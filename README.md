## 按人数和玩法挑档位

MC 服吃单核和内存，不吃显卡，也很少吃多核。官方在产品页给了一套参考基准：纯净服/基岩服按视距 6 算，MOD 服按 50 个 mod、视距 5 算，并明确写了 1.18+ 版本的资源消耗大约是 1.16+ 的两倍、1.12.2 的三倍。

按这个基准，官方对 2核4G / 4核8G / 6核12G 三档的承载量标注是：

- 2核4G：纯净服 12+ 人 / mod 服 6 人 / 200+ mod 整合包 1 人
- 4核8G：纯净服 25+ 人 / mod 服 15 人 / 整合包 5 人
- 6核12G：纯净服 40+ 人 / mod 服 20 人 / 整合包 8 人

注意这是高频 CPU 机型下的数据。换成 E5 2666v3 或 Platinum 8259cl 这类平台，人数得往下砍——公开的第三方整理里，同样是 2核4G，E5 平台标的是纯净服 5 人、mod 服 3 人。所以选配置的正确顺序是：先定版本和玩法，再定 CPU 机型，最后定核数内存。

具体一点：

- **两三个人玩 1.12.2 以下的纯净生存**：最低档就够，E5 或 8259cl 都能跑。
- **五到十几人的高版本插件服（1.18+）**：直接上 Ryzen 或 i9 机型，2核4G 起步，内存别低于 4G。
- **几十人的模组服或整合包服**：4核8G 起步，优先高频 CPU，内存留余量。整合包 200+ mod 的情况下，2核4G 只能带 1 个人。
- **群组服、多服务端、需要独立公网 IP**：走 VPS 线，面板服在这类场景下会卡在端口和容器限制上。

## 动态计费还是固定计费

雨云的付费游戏云有两种计费方式，选错了每个月能多花不少。

固定计费就是传统月租，按月收，不管服务器负载高低。

动态计费是低价月租加上按 CPU 使用情况结算的额外费用，低负载时段计费基本停住，高峰时按实际消耗走。官方描述是“闲时省钱、忙时火力全开”。

判断标准很朴素：如果你的服一天只有晚上三四个小时有人，选动态计费；如果是 24 小时常开、玩家全天在线的商业服，固定计费反而更可控，不用担心某个晚高峰把预算顶穿。签到拿到的积分也能用来补充动态计费的消耗。

## 从付款到进游戏：实际操作顺序

以 MCSM 面板服为例，整个流程比想象中短：

1. 在购买页选服务器类型（新手直接选 MCSM 面板）、地区、配置和计费方式，付款。地区建议选离你和朋友最近的节点，这个直接决定 ping 值。
2. 回到“我的游戏云”，点管理，进入重装/更新游戏，选择服务端类型和版本。Paper 适合插件服但不支持 mod，Forge/Fabric 走 mod 路线，整合包有对应模板。
3. 打开 MCSM 控制台，点启动。等日志刷出 `Done (xx.xxxs)! For help, type "help"`，说明开服成功。
4. 如果是离线玩家或盗版客户端，进 `server.properties` 把 `online-mode=true` 改成 `false`，保存后重启实例。不改的话只有正版账号能进。
5. 回到雨云控制台，在信息与监控里找 NAT 端口映射，复制标着游戏端口的那一条，格式是 `公网IP:端口`。把这串地址发给朋友，在多人游戏里添加服务器就能进。
6. 给自己开权限：控制台输入 `op 你的游戏ID`，注意不带斜杠。

## 新手最容易踩的坑

**端口别乱改。** 面板服的防火墙只放行系统分配的端口，改了配置也没用，重启自动复原，改完的结果通常是所有朋友都连不上。

**内存参数别自己写。** 启动参数里填了 `-Xmx`，容器环境直接判失败。这是免费档和一键开服面板最常见的一开就关的原因。

**eula.txt 要先启动一次才有。** 想手动改 EULA 的话，得先启动过一次服务端，否则文件还没生成。

**E5 平台开高版本服会卡。** 1.18+ 对单核性能的要求明显拉升，E5 2666v3 这类低主频平台跑高版本纯净服还行，上模组就会掉 tps。这不是雨云一家的问题，是硬件规律。

**备份要开。** 面板自带备份功能，但玩家自己写的脚本、配置文件不一定在里面。存档积累到几十个小时以后，丢一次成本很高。
